- **Bug found and fixed during testing — submitting after a save conflict used to submit anyway.** `use-writing-activity.ts`'s `submit()` originally did `flushed?.revision ?? viewRef.current?.draft.revision` — when `flush()` returned `null` for *any* reason (a genuine conflict, a mid-flight busy guard, or a network failure), it silently fell back to the stale `baseRevision` already in the view and called `POST …/submit` anyway.
